============================================================
  CHAT APPLICATION — COMMAND REFERENCE
============================================================

------------------------------------------------------------
 1. GOOGLE CLOUD VM — START SERVER
------------------------------------------------------------

Step 1 — Pull latest code:
  git pull

Step 2 — Start the server:
  mvn compile exec:java@server


------------------------------------------------------------
 2. WINDOWS PC — RUN CLIENT (quick)
------------------------------------------------------------

Step 1 — Run the existing JAR:
  java -jar target\ChatApplication-1.0-SNAPSHOT.jar


------------------------------------------------------------
 3. WINDOWS PC — FULL BUILD FROM SCRATCH
------------------------------------------------------------

Step 1 — Clean and compile:
  mvn clean compile

Step 2 — Package JAR:
  mvn package

Step 3 — Run the JAR:
  java -jar target\ChatApplication-1.0-SNAPSHOT.jar


------------------------------------------------------------
 4. WINDOWS PC — RUN CLIENT (development mode)
------------------------------------------------------------

Step 1 — Compile and launch with JavaFX:
  mvn compile javafx:run


------------------------------------------------------------
 5. WINDOWS PC — BUILD PORTABLE .EXE (no Java needed)
------------------------------------------------------------

Step 1 — Set JDK 24 (run in PowerShell):
  $env:JAVA_HOME = "C:\Program Files\Java\jdk-24"
  $env:PATH = "$env:JAVA_HOME\bin;$env:PATH"

Step 2 — Build JAR:
  mvn clean package

Step 3 — Create portable app folder:
  jpackage --type app-image --name "ChatApplication" --app-version "1.0" --input target --main-jar ChatApplication-1.0-SNAPSHOT.jar --main-class com.chat.client.Launcher --dest dist --java-options "--add-opens=javafx.graphics/com.sun.javafx.application=ALL-UNNAMED"

Step 4 — Zip for sharing:
  Compress-Archive -Path "dist\ChatApplication" -DestinationPath "ChatApplication-portable.zip" -Force

  OR just double-click: build-installer.bat  (does steps 1-4 automatically)


------------------------------------------------------------
 6. GIT — PUSH CHANGES
------------------------------------------------------------

Step 1 — Stage all changes:
  git add .

Step 2 — Commit:
  git commit -m "your message here"

Step 3 — Push to GitHub:
  git push
